# Developer Profile Page

A simple developer profile page built with HTML and CSS for the **Week 01** web development task by Team HackerEarth Hub NMAMIT.

I'm **Priyadarshini**, a second-year AIML student at NMAMIT. This page introduces me, my skills and my projects, and includes a contact form.

## Sections

- **About Me**: a short introduction
- **Skills**: the languages I am learning (Python, C, Java)
- **Projects**: projects I have built
- **Contact**: a contact form with name, email and message fields

## Built With

- HTML5, using semantic elements (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3, for basic colours and styling

## Project Structure

```
web-dev-week-01/
├── index.html    # page structure and content
├── style.css     # styling
└── README.md     # project description
```

## How to Run

1. Clone or download this repository.
2. Open `index.html` in any web browser.

No installation is needed.

## Notes

The contact form does not send messages yet. It only demonstrates form structure.
